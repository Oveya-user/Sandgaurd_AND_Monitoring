# SandGuard – Smart Sand Mining Monitoring System

## About the Project

SandGuard is a smart sand mining monitoring and early warning system designed to monitor sand mining activities in Tamil Nadu river basins.

## Key Features

- AI-powered sand mining activity detection
- Geofencing for protected riverbeds
- Permit verification
- Monitoring dashboard
- Early warning alerts

## Technologies Used

- React
- JavaScript
- HTML
- CSS
- AI-based monitoring
